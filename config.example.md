# Local config (template) · 本机配置（模板）

> You don't need to copy this by hand. **On first run, Claude asks where your notes should go and writes `config.md` for you.**
> To configure manually: copy this file to `config.md` in the same folder and change the path.
>

> 想手动配也行：把这份复制成同目录下的 `config.md`，改掉路径即可。
