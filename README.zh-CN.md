# Build to Learn 使用指南

[English](README.md) | **简体中文**

> 这份给人读。`SKILL.md` 和 `references/` 是 AI 的执行规则，你不用看。

## 这是干嘛的

你想做一个东西，又想真的学会它背后的技术——这个 skill 管这件事。

它防一种病：AI 一把梭把代码写完，东西能跑，你啥也没学到。所以这里的规矩反过来：**学会是目的，做出来的东西是检验你学没学会的证据。**

代码全由 AI 写，你不需要会编程。

## 装它

前提：你在用 [Claude Code](https://claude.com/claude-code)。

```bash
git clone <这个仓库> ~/.claude/skills/build-to-learn
```

放在 `~/.claude/skills/` 下是全局可用；只想在某个项目里用，就放进那个项目的 `.claude/skills/`。

### 笔记放哪：不用配，它会问你

第一次启动时，AI 会先问一句「学习笔记放哪」，默认 `~/Documents/Build To Learn`。你答完它建好目录、记进 `config.md`，以后不再问。

路径随便挑一个文件夹就行。用 Obsidian 的话指进你的库里，笔记里的 Mermaid 图和折叠自测题会直接渲染；不用 Obsidian 也没关系，那些文件本来就是普通 Markdown。

想换位置：改 `config.md` 里那一行，或者直接跟 AI 说。这份文件不进 git，你的路径不会被更新覆盖掉。

## 怎么开始

输入 `/build-to-learn`，或者直接说「带我做个 XX，我想学会」。

第一次启动，你手里一个项目都没有，AI 会给你两个选择：开个新项目，或者先看这份教程。

之后每次启动，它先列出你已有的项目和各自卡在哪，让你选：续做哪个，还是开新的。**续做不会重新立项**，它读一份「学习地图」就能从断点接上——换设备、换对话、隔一个月，都接得上。

## 你和 AI 怎么分工

你干的是三件 AI 替不了的事：

**1. 拍决策。** 方向性的选择会摆到你面前，你拍板了 AI 才动手。比如「界面放原生窗口还是网页」。「用哪个函数」这类实现细节不会来烦你。

**2. 亲手跑。** 跑命令、点按钮、看现象，这些动作永远是你的。AI 把台搭好、指给你位置，然后停下来等你。

> **AI 停下来不是卡了，是在等你动手。** 这是最常见的误会。你把看到的现象告诉它，它再讲透为什么。

**3. 答通关题。** 每个阶段收尾时 AI 考你一道题（就一道），检验这阶段真学进去没有。

还有一条贯穿全程：你随时冒出的「为什么」是全场优先级最高的事。问出来，AI 会停下主线陪你挖透，再带你回来。

## 一个项目会经历什么

四个阶段。立项走一次，施工和通关每个阶段循环一轮，笔记全程自动。

### 1. 立项：把想法聊成计划

AI 会依次做这几件事，全程不谈技术：

1. **听你讲**。你把想做的东西讲一遍，它不打断。同时它去翻你的能力库，看你以前攒过什么能直接用上。
2. **追问细节**。一次只问一个问题，每个问题都带 2-3 个具体选项，你挑一个或者改。问的全是产品：给谁用、什么时候用、「划的是一整段呢」「没网呢」。
3. **摊出能力清单**。你的想法被拆成几块能力，每块用人话命名，并标上：能力库里有现成的 ✅ / 世上有现成技术 ✔ / 这里有堵墙你会撞上 ⚠️ / AI 也不确定 ❓。
4. **让你猜**。「这几块你觉得哪块最麻烦？」你的猜想会被记到对应阶段上，后面亲手撞到时回来对答案。
5. **问你想学到什么程度**。三档：只要跑通 / 能讲出原理 / 能迁移着做下一个。这决定后面哪些活 AI 直接干、哪些必须你参与。
6. **给技术路线**。两三条，带人话取舍和它的推荐，你拍板。不会问你「用 SwiftUI 还是 AppKit」这种。
7. **摆确认清单**。五样东西列出来让你逐条点头：产品一句话、场景清单、什么算做成、学习档位、第一架阶梯。**这五样没确认前，它一行代码不写、一个文件不建。**
8. **建文件夹**，告诉你笔记和代码分别落在哪。

**阶梯长什么样**：一行一个阶段。第一阶段就是一个能跑的最小版本，之后每阶段加一块，始终能跑。

下一个阶段写得细，再往后一个阶段只有一行字，更远的写「待定，做到再拆」。远处故意不写细——因为你真做起来以后它一定会变。**阶梯是路标，不是合同。**

### 2. 施工：一块一块长出来

**开工第一件事是一张图。** 这阶段的东西由哪几个部件组成、数据从哪流到哪，画成一张图（≤7 个部件）。图上标了两样：哪些是上阶段就有的、哪些是这阶段新长的；哪些是承重部件、哪些是样板代码。

这张图是学习的本体。后面每一轮 AI 都会先指着图说「现在讲 X 到 Y 这条边」——你永远知道自己在哪。图上还挂着这阶段要你拍的决策，但**只列问题不给答案**，做到那个部件了才轮到你拍。

之后照着图，一条边一条边走。每个承重部件的节奏固定：

1. 它为什么存在、起什么作用
2. 大白话讲它怎么实现的（先不碰代码）
3. 代码怎么诠释这套逻辑
4. **你亲手跑，亲眼看现象**

有些实验是故意设计成会失败的——亲手撞一次墙，比听十遍讲解记得牢。撞完你把现象带回来，AI 当场把因果讲透。

**施工期 AI 不考你。** 它讲、你跑、它讲透，就这个循环。检验集中在阶段末尾，不打断你的手感。

AI 一次只推进一小步，讲完就停。嫌慢可以催，嫌快随时喊停。

### 3. 通关：验收加考一道

整个阶段第一次完整跑起来之前，AI 会说一句「心里押一下会跑成啥样」——**不用回答**，你想不想都行，接着就交棒让你跑。跑完它拿真实现象跟你的预期对一遍。

跑通了，才进考试：

- **就一道题。** AI 挑当时最值得考的那个角度出题，四个小问以内。
- 最常见的考法是**给你一个没教过的新需求**，让你说四件事：动哪个部件、照什么形状做、会踩哪个坑、AI 做完你怎么验收。
- 说思路就行，不求漂亮。**答错正好暴露该回炉的地方**，这就是它的用处。

答完 AI 给你一张认知地图：哪块结实 ✅、哪块还虚 🔶，虚的那块对应接下来哪个阶段补。考试接回建造主线，不是为考而考。

然后它做四件收尾：把这阶段的笔记写成复盘文、把新学的能力登记进能力库、刷新学习地图、重看一遍阶梯（远处的阶段还成立吗？下一阶段现在能写细了）。

### 4. 笔记：全自动，你不动笔

| 产物 | 给谁看 | 干什么用 |
|---|---|---|
| 学习地图 | 主要给 AI | 换个对话、隔一个月，都能从断点无缝接上 |
| 学习记录 | 给你 | 每阶段一篇复盘文，读一遍等于复习一遍。带 Mermaid 图、带折叠的自测题 |
| 能力库 | 你和 AI | 跨项目攒能力卡。库越厚，下个项目越敢想 |

中途随时可以走，说一句「存档」就行。下次回来，AI 先给你一道回忆题——**题和答案一起给**，你自己心里对照，对不上再让它带你复习。

## 文件都在哪

```
你配置的那个文件夹/
├── _项目索引.md          所有项目一览（AI 每次开场自动重写）
├── _能力库.md            跨项目的能力卡，所有项目共用
└── 你的项目名/
    ├── 学习地图.md        给 AI 的交接单：进度、手悬在哪、下一步干什么
    └── 学习记录/
        ├── S1 · xxx.md    给你的复盘文，一个阶段一篇
        └── S2 · xxx.md
```

**代码不放这里。** 代码放能构建的地方（比如 `~/Projects/你的项目`）。如果做的是真产品，代码目录里还会有一份 `PLAN.md`：产品是什么、架构什么形状、拍过哪些决策、为什么。

## 你手里的口令

这些话随时说，AI 立刻响应：

| 你说 | 会发生什么 |
|---|---|
| 「等等，我有问题」 | 立刻刹车，纯答疑，不往下推 |
| 「这段没懂，换个说法」 | 就地把那块放大讲透，讲完拎你回主线 |
| 「太顺了 / 没踩实」 | AI 让你挑一个最虚的部件，然后**故意弄坏它**，让你亲手验证你以为懂了的地方 |
| 「快点 / 慢点」 | 调步长 |
| 「先别写代码，我想想」 | 停在决策上等你 |
| 「这阶段太大了，拆开」 | 当场改阶梯，拆成两个都能跑的阶段 |
| 「存档 / 先到这」 | 进度全量记盘，下次回来从断点接上 |
| 「别考了，往下」 | 跳过考试，记一笔欠账，下次补 |
| 「续做 XX」 | 跳过列清单，直接接上那个项目 |
| 「别教我，直接做完」 | 退出这套流程，按普通方式帮你做完 |

## 你可以自己改什么

笔记全是普通 Markdown，你随时能开、能改。但有的会被 AI 覆盖，改之前知道一下：

| 文件 | 手改保得住吗 |
|---|---|
| `学习记录/S*.md` | **保得住**。这是给你的，随便批注、随便加。AI 只在那个阶段通关时整篇重写一次，之后基本不碰 |
| `学习地图.md` | **「现在在哪」那一段会被覆盖**，因为 AI 每推进几步就全量刷新它一次。其他区手改能留住 |
| `_项目索引.md` | **别手改**，每次开场都覆盖重写 |
| `_能力库.md` | 保得住，AI 只追加卡片和修订边界 |

**阶梯随时能改。** 「这阶段太大」「这个先不做」「先做那个」——说了就改，它本来就是当前最佳猜想。改阶梯不是计划失败，是计划在正常工作。

## 什么时候别用它

只想要成品、不想学：直说「别教我，直接做完」，AI 会按普通方式帮你做完，不走这套流程。
